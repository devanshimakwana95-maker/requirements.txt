# 🌸 Language Learning Assistant 🌸

A gamified, adaptive language learning app built with **Streamlit**.  
Supports **120+ languages**, daily vocabulary limits, gamified tasks, AI review, motivation boosts, and performance charts.

---

## 🚀 Features
- 👤 **Profile**: Save your name, age, and learning level (Beginner, Intermediate, Pro).
- 📖 **Vocabulary**: Add and store words with translations in 120+ languages.
- 🔎 **Translation**: Translate any word instantly using Google Translate API.
- 🔊 **Pronunciation**: Hear words spoken aloud with gTTS.
- 🎮 **Daily Tasks**: Fun mini‑games (scramble, fill‑in‑the‑blank, multiple choice).
- 📊 **Performance Chart**: Track words learned and quiz scores over time.
- 💡 **AI Review**: Get smart suggestions tailored to your level.
- 🚀 **Motivation Boost**: Daily quotes to keep you inspired.
